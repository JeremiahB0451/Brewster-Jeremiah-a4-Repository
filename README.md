# Brewster-Jeremiah-a4-Repository
A 2D game

Space shooter game:
Accelerate with arrow keys.
Press space to shoot a ball in the direction you're moving.
Shoot the enemies.
A ball that has hit a wall can pirce more enemies and award more points. 
THERE CAN ONLY BE ONE BALL ON SCREEN.
Don't let the enemies touch you or reach the bottom.
Try to get a highscore.
